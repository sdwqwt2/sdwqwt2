**[Рекомендательная система на Yambda-50M](https://github.com/sdwqwt2/music-recommender-system)** · PyTorch, Pandas, Parquet · [препринт](https://github.com/sdwqwt2/music-recommender-system/blob/main/reports/latex/main_en.pdf)

*   **Данные:** собрал воспроизводимый пайплайн для ~50 млн событий Яндекс Музыки: приведение схемы, фильтрация, кодирование ID, разбиение по времени без утечек.
